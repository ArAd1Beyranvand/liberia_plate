## Quick start

### Install (TypeScript)

Copy `typescript/src/countries/liberia/` into `plate_core/typescript/src/countries/`.

Then run the tests from `plate_core/typescript/`: `npm test`.

### Use

```ts
import country from './countries/liberia';

const spec = country.specs.get('lr.diplomatic');
console.log(country.package);
```

## Specs

The specs are the same in every language (they come from shared data).

- `lr.diplomatic`

## Themes

- `LiberiaThemes.diplomatic`

## Change it

- Specs: `country.specs`, by id.
- Themes: `country.themes`.
- Validators: `country.validators` (`LiberiaValidator`).
