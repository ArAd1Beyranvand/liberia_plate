## Quick start

### Install (Kotlin)

Copy `kotlin/src/commonMain/kotlin/plates/countries/liberia/` into `plate_core/kotlin/src/commonMain/kotlin/plates/countries/`.

Then run the tests from `plate_core/kotlin/`: `./gradlew jvmTest`.

### Use

```kotlin
import plates.countries.liberia.country

val spec = country.specs["lr.diplomatic"]
println(country.pkg)
```

## Specs

The specs are the same in every language (they come from shared data).

- `lr.diplomatic`

## Themes

- `LiberiaThemes.diplomatic`

## Change it

- Specs: `country.specs`, by id.
- Themes: `country.themes`.
- Validators: `country.validators` (`LiberiaValidator`).
