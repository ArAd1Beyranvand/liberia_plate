## Quick start

### Install (Python)

Copy `python/plates/countries/liberia/` into `plate_core/python/plates/countries/`.

Then run the tests from `plate_core/python/`: `pytest`.

### Use

```python
from plates.countries.liberia.data import SPECS, THEMES

spec = SPECS["lr.diplomatic"]
theme = THEMES["LiberiaThemes.diplomatic"]
print(spec.id)
```

## Specs

The specs are the same in every language (they come from shared data).

- `lr.diplomatic`

## Themes

- `LiberiaThemes.diplomatic`

## Change it

- Pick a spec: use another key of `SPECS`.
- Pick a theme: use another key of `THEMES`.
- Validators: `VALIDATORS` maps the names `LiberiaValidator` to classes.
